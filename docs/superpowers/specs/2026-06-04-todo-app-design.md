# 待办事项 App 设计文档

## 概述

一个面向 2-5 人小团队的看板式待办事项管理应用，采用深色酷炫风格，支持网页端和手机端。

## 目标用户

- 2-5 人小组团队
- 需要协作管理任务、分配工作

## 技术选型

- **前端框架**：React
- **响应式设计**：网页端优先，适配手机端
- **拖拽库**：react-beautiful-dnd 或 @dnd-kit
- **状态管理**：React Context（轻量，适合小项目）
- **样式方案**：CSS Modules 或 styled-components

## 核心功能

### 1. 看板视图（三列固定）

| 列名 | 说明 |
|------|------|
| 待办 | 新建任务默认进入此列 |
| 进行中 | 正在处理的任务 |
| 已完成 | 已完成的任务 |

- 任务卡片可在三列之间拖拽移动
- 每列顶部显示列名和任务计数
- 每列底部有「+ 添加任务」按钮

### 2. 任务卡片

每张卡片展示以下信息：

- **优先级标识**：左上角色块（红=高、黄=中、绿=低）
- **任务标题**：居中显示
- **指派人**：左下角，头像+名字
- **截止日期**：右下角，临近截止变红色

交互：
- 拖拽在列间移动
- 点击弹出详情面板
- 悬停时微微上浮 + 阴影效果

### 3. 任务详情面板

点击卡片后从右侧滑入，包含：

- **状态**：下拉选择（待办/进行中/已完成）
- **指派人**：下拉选择团队成员
- **优先级**：下拉选择（高/中/低）
- **截止日期**：日期选择器
- **描述**：多行文本输入
- **操作按钮**：保存、删除（删除需二次确认）

面板弹出时背景变暗，不完全遮挡看板。

### 4. 顶部导航栏

- 左侧：Logo / 项目名称
- 右侧：搜索框、通知图标、用户头像

固定在页面顶部。

## 界面风格

### 深色主题配色

| 用途 | 色值 | 说明 |
|------|------|------|
| 背景色 | `#1a1a2e` | 深蓝黑 |
| 卡片背景 | `#16213e` | 深蓝灰 |
| 导航栏 | `#0f3460` | 藏蓝色 |
| 主强调色 | `#533483` | 紫色，按钮/高亮 |
| 文字主色 | `#e0e0e0` | 浅灰白 |
| 文字次色 | `#8892a0` | 灰色，次要信息 |
| 高优先级 | `#e74c3c` | 红色 |
| 中优先级 | `#f39c12` | 黄色 |
| 低优先级 | `#2ecc71` | 绿色 |

### 设计原则

- 科技感强，长时间使用不刺眼
- 卡片之间有适当间距，视觉清晰
- 悬停和拖拽有流畅的动画反馈

## 响应式设计

- **网页端**：三列并排显示
- **手机端**：三列改为横向滑动切换，每次显示一列

## 页面结构

```
App
├── 顶部导航栏 (Navbar)
│   ├── Logo / 项目名
│   ├── 搜索框
│   ├── 通知图标
│   └── 用户头像
├── 看板主体 (Board)
│   ├── 待办列 (Column: Todo)
│   │   ├── 任务卡片 (TaskCard) ×N
│   │   └── 添加任务按钮
│   ├── 进行中列 (Column: InProgress)
│   │   ├── 任务卡片 (TaskCard) ×N
│   │   └── 添加任务按钮
│   └── 已完成列 (Column: Done)
│       ├── 任务卡片 (TaskCard) ×N
│       └── 添加任务按钮
└── 任务详情面板 (TaskDetailPanel)
    ├── 状态选择
    ├── 指派人选择
    ├── 优先级选择
    ├── 截止日期选择
    ├── 描述文本框
    └── 保存 / 删除按钮
```

## 数据模型

### Task（任务）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一标识 |
| title | string | 任务标题 |
| description | string | 任务描述 |
| status | enum | todo / in_progress / done |
| priority | enum | high / medium / low |
| assignee | string | 指派人ID |
| dueDate | date | 截止日期 |
| createdAt | datetime | 创建时间 |
| updatedAt | datetime | 更新时间 |

### User（用户/团队成员）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一标识 |
| name | string | 名称 |
| avatar | string | 头像URL |
